# Logos

The Bloom mark (a drop with a crescent cut-out, held by two leaves) and the wordmark (the mark with "Bloom" in Playfair Display SemiBold). All vector, outlined — no font needed.

| File | Use |
| --- | --- |
| `bloom-wordmark.svg` | Default lockup on `background` or `surface`: text `ink` (#2D1A24), mark `primary` (#A23B6D) and `petal` (#E8A1BE). |
| `bloom-wordmark-reversed.svg` | On `hero-start` or darker: cream (#FFF7F0) text, petal mark. |
| `bloom-wordmark-mono.svg` | Single ink, black (#000000). Recolour to white or one brand colour for one-colour print. |
| `bloom-mark.svg` | The mark alone: favicons, avatars, small spaces (minimum 24 px). |
| `bloom-mark-reversed.svg` | The mark on dark grounds: petal and cream. |
| `bloom-mark-mono.svg` | Single ink, black (#000000). |
| `bloom-lockup-tagline.svg` | Wordmark with "Your cycle, understood." for launch and marketing. |
| `bloom-app-icon.svg` | The app icon artwork (square; the platform applies the mask). |
| `bloom-app-icon-rounded.png` | 512 × 512 rounded preview of the app icon for decks and store listings. |

Keep clear space of at least the crescent's height on every side. Don't recolour outside these versions, stretch, outline, add shadows, or place on busy photos.
