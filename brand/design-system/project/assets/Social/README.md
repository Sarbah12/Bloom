# Social

Ready-to-post templates built from the brand palette, the mark and the wordmark.

| File | Size | Use |
| --- | --- | --- |
| `avatar.png` | 1080 × 1080 | Profile picture; the mark centred on the hero gradient, safe inside a circle crop. |
| `instagram-post.png` | 1080 × 1350 | Launch post (4:5). |
| `instagram-story.png` | 1080 × 1920 | Story (9:16); keep text clear of the top and bottom 250 px. |
| `banner.png` | 1500 × 500 | X / LinkedIn header; key content centred for mobile crops. |
| `play-feature-graphic.png` | 1024 × 500 | Google Play feature graphic. |

Regenerate from `brand/social/*.svg` with `npm run build:brand` after any palette or logo change.
