# PhaseBadge

A small pill that names the current cycle phase on its soft colour, with a solid dot.

## Anatomy

- Background `<phase>-soft`, label `<phase>-on-soft` in `caption`, dot 8 px in the phase solid.
- Radius `radius-pill`; padding `space-xs` `space-md`.

## Rules

- Phases after the period are estimates and say "· Estimated" unless confirmed by logs.
- Ovulation is always an estimate and never described as a safe or unsafe time.
- Use under the cycle ring and in calendar day details — not as decoration.

## What the consumer provides

The phase (`menstrual`, `follicular`, `ovulatory`, `luteal`) and whether it is estimated.
